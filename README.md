# PatiAlan V0.1

Türkiye için private pet spaces pazaryeri MVP'si. İlk pilot İstanbul'da doğrulanmış özel köpek alanlarının 30/60/90 dakikalık rezervasyonu üzerine kuruludur.

## Stack
- Next.js 16.3.5 App Router
- React 19.3.0
- Supabase Auth + Postgres + Storage + RLS
- @supabase/ssr 0.12.7
- @supabase/supabase-js 2.116.0

## Durum
Kaynak kodu bu repoya aktarılıyor. Canlı Supabase backend için Free plan proje kotası nedeniyle ayrı slot gerekiyor.
